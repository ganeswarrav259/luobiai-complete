# 落笔 AI 创作复现版

一个面向短剧、小说和提示词创作的 React 单页应用，包含订阅套餐、积分充值、项目管理与剧本编辑体验。

## 功能

- 登录、注册申请和找回密码界面
- 短剧、小说、提示词和回收站管理
- 七种短剧项目创建方式
- 三档订阅套餐和三档积分包
- 套餐状态、有效期和积分余额持久化
- 剧本编辑、AI 续写、角色与分镜入口
- 团队设置、用户后台和深色模式
- 桌面与移动端响应式布局

## 本地运行

```bash
npm install
npm run dev
```

默认访问地址：`http://127.0.0.1:4317/`

演示账号：`demo@luobi.ai`  
演示密码：`12345678`

## 构建

```bash
npm run build
```

## 说明

套餐购买、积分充值、邮件和 AI 生成均为前端模拟流程，数据保存在浏览器本地。接入真实服务需要自行实现后端订单、支付回调、邮件和模型 API。

本项目仅用于界面与交互演示，与原网站及其运营方无隶属或授权关系。
